# MP-MediaInfo 26.10.0

MediaInfoLib 26.10. New asynchronous analyzer and `MediaInfo.Analysis.Rtsp` package. Previous release: 26.1.0.

| Package | Frameworks | Native package |
| --- | --- | --- |
| `MediaInfo.Wrapper.Core` | netstandard2.1, net8.0, net10.0 | `MediaInfo.Core.Native` 26.10.0 |
| `MediaInfo.Wrapper` | net4.0, net4.5, net481 | `MediaInfo.Native` 26.10.0 |
| `MediaInfo.Analysis.Rtsp` (new) | netstandard2.1, net8.0, net10.0 | via `MediaInfo.Wrapper.Core` |

## Added

- `IMediaInfoAnalyzer` ([guide](https://github.com/yartat/MP-MediaInfo/blob/master/docs/async-api.md)): `AnalyzeAsync` for files, URLs, streams and discs; `AnalyzeFolderAsync`; DVD and Blu-ray titles and chapters from their navigation tables; `MediaInfoAnalyzerBuilder` (validation, caching, timeout, retry, concurrency limit, external subtitles); `AddMediaInfoAnalyzer` for dependency injection; `AsLegacy()` for code written against `MediaInfoWrapper`.
- `MediaInfo.Analysis.Rtsp`: analysis of H.264 and H.265 `rtsp://` sources.
- `AudioStream.DynamicObjects`: Dolby Atmos and DTS:X object count.
- `SubtitleStream.MaxCharactersPerLine`.
- `VideoStream.Rotation`, `ScanType`, `DisplayAspectRatio`.
- `AudioStream.AudioChannelsFriendly` returns `7.1.4` for 12 channels.
- Codecs: A-law, mu-law, G.722, G.726, G.729, GSM, Speex, EVRC, IAMF; DVB, Kate, EIA-608/708, Apple text, timed text, DivX subtitles; AVS, AVS2, VC-3, Cinepak, JPEG 2000; HLG+ and more HDR metadata names.
- P/Invoke declarations for the remaining MediaInfoLib exports, including the tag write API.

## Changed

- MediaInfoLib 26.01 to 26.10 ([history](https://github.com/MediaArea/MediaInfoLib/blob/master/History_DLL.txt)). Visible differences:
  - DTS:X reports 12 channels (7.1.4) instead of 8; its objects are in `DynamicObjects`.
  - Five-channel Opus is 5.0, not 4.1.
  - MP3 duration and bit rate are more accurate with encoder delay or a Xing header.
  - `MediaInfoList.Open` honours `InfoFileOptions`.
- `MediaInfoWrapper` is obsolete on .NET. It is not marked on .NET Framework.
- `MediaInfo.Wrapper.Core` drops .NET 6. `MediaInfo.Wrapper` adds net481.

## Fixed

- Heap corruption: strings owned by the native library were freed by the runtime.
- Unicode file names on Linux and macOS.
- DVD and Blu-ray folder detection on case-sensitive file systems.
- `MediaInfoWrapper` no longer passes a missing file to the native library.

## Known limitations

- The analyzer and the RTSP package require .NET Standard 2.1 or later.
- RTSP: video must be H.264 or H.265; audio is described, not played; `Duration` and `Size` are 0.
- Analyzing a file or a URL cannot be cancelled while the native library opens it.
